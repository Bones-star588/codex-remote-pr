# Product

## Register

product

## Users

A trusted operator continuing their own Codex Desktop chats from a phone or
another computer. They need to read progress, send instructions, review changes,
and answer approvals without losing the desktop's shared state.

## Product Purpose

Render the Codex Desktop workflow as a responsive web workspace, using the
desktop's owning backend. Preserve complete, incrementally loaded histories
while keeping long tool sequences readable and inexpensive to display.

## Brand Personality

Quiet, familiar, precise. Follow Codex Desktop and the existing codex-webui
reference rather than inventing a separate visual identity.

## Anti-references

Marketing layouts, decorative dashboard cards, explanatory text in routine
controls, oversized status badges, replacement fonts, and expanded tool logs
that overwhelm the conversation.

## Design Principles

- Keep live commentary in order; merge consecutive commands, edits, tools and
  searches across types. Completed turns fold their process and commentary
  under the native duration disclosure, leaving the final reply visible.
- Reflect native state accurately; distinguish a tool failure from turn status.
- Preserve reading position during streaming and history navigation.
- Make desktop scanning and phone interaction equally practical.
- Reuse the existing light palette, system typography, and compact controls.
- Keep shell, authenticated data and live connection readiness distinct.
  A returning-device hint can open an empty UI but never grants access.

## Accessibility & Inclusion

Preserve keyboard operation, visible focus, descriptive control names, status
labels independent of color, reduced-motion support, and touch-sized controls.
Do not claim a formal accessibility certification.
